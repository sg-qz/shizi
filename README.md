# 识字启蒙工作台

一个给 5 岁小朋友做的**单文件汉字启蒙 Web 应用**，手机 / 平板 / 电脑浏览器打开即用，可「添加到主屏幕」当 APP 用。

> 零依赖、零外链：整个应用就是一个 `index.html`，双击即可在浏览器运行。

## ✨ 功能模块

| 模块 | 说明 |
| --- | --- |
| 📅 今天 | 按「每天 10 个字」规划学习，顶部进度环显示当天完成情况；昨天没学完会自动顺延。 |
| 🃏 卡片 | 象形字翻转卡：正面大字 + 拼音，点一下翻面看「原来样子」（手绘 SVG 象形图）+ 小故事；点「我学会啦」+10 分。 |
| 🔤 组词 | 给字、从 3 个词里选出含该字的词，答对 +5 分，答错有抖动提示。 |
| 🏆 闯关 | 实时积分与关卡进度条；内置「奖励小超市」，孩子点兑换 → 家长确认扣分发奖。 |
| 🌱 成长 | 累计学习天数、已学字数、录音次数、当前关卡、识字总进度、学习日历、录音徽章墙、已兑换奖励历史。 |
| 🔁 巩固 | 展示**所有已学汉字**，点一下听发音 + 看拼音；「开始巩固复习」用已学字做组词小测验。 |
| 👨‍👩‍👧 家长 | 4 位数字密码保护；可改每日字数、增删奖励、确认兑换、导出 / 导入备份、清空数据，以及设置「跳过已学汉字」。 |

## 🔤 字库

- **400 字**：对齐「一年级上册必认字 280 字」+ 120 个常用拓展字。
- 学习进度**优先前 280 字**（核心字先学，拓展字殿后补充）。
- 拼音用 `pypinyin` 生成并人工校正多音字；每字内置 2–3 个常用组词。
- 40 余个象形字配有手绘 SVG 原字图。

## 🎤 拼音跟读 / 录音

- 「🔊 听一听」：用浏览器语音合成朗读汉字。
- 「🎤 录一录」：录制孩子跟读声音，停止后生成「🔊 我的声音」回放按钮（录音仅本地回放，不上传）。

## 🚀 使用方式

**方式一：直接打开**
下载 `index.html`，双击用浏览器打开即可使用（数据保存在本机浏览器）。

**方式二：部署到任意静态托管**
把 `index.html` 放到任意静态网站服务（GitHub Pages / Vercel / Netlify / 对象存储）即可在线访问。

## 📝 数据存储说明

- 应用优先使用 WorkBuddy 资料库云表做多设备同步；**在未接入资料库的环境下（如本仓库直接打开 / GitHub Pages）会自动降级为浏览器本地存储**，功能完全正常，进度保存在本机。
- 家长可随时在「家长」页「导出 / 导入备份」做数据迁移。

## 🛠 技术栈

纯前端单文件 HTML + 原生 JavaScript + 内联 CSS + 内联 SVG，无任何构建步骤与第三方依赖。
